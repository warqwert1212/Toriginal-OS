=S - Build & Installation Quick Reference

### Quick Build

```bash
cd /workspaces/Toriganal-OS
make all              # Build kernel and shell
make install          # Install to ./install
make run-shell        # Run Toriginal OS shell
```

### Build Directory Structure

```
build/
├── freeNT            # Compiled kernel executable
├── toriginal_shell   # Compiled shell executable
├── CMakeFiles/
├── Makefile          # Generated by CMake
└── *.cmake           # CMake cache files

install/
├── boot/
│   └── freeNT        # Kernel binary
├── bin/
│   └── toriginal_shell  # Shell executable
└── lib/              # Libraries (future)
```

### System Files

**Kernel Sources:**
- `/freeNT/src/kernel/*.c` - Core kernel implementations
- `/freeNT/src/kernel/include/*.h` - Kernel headers
- `/freeNT/src/kernel/boot/boot.S` - Assembly bootloader

**Shell Sources:**
- `/shell/src/shell.cpp` - Shell implementation
- `/shell/src/main.cpp` - Entry point
- `/shell/include/shell.h` - Shell header

**Build Configuration:**
- `/CMakeLists.txt` - Master build file
- `/freeNT/CMakeLists.txt` - Kernel build
- `/shell/CMakeLists.txt` - Shell build
- `/Makefile` - Build shortcuts

### File System Layout (/sys/userpc/~)

```
sys                  (Entire drive)
└── userpc           (User personal area)
    └── ~            (User home)
        ├── bin/     (Executables)
        ├── lib/     (Libraries)
        ├── tmp/     (Temporary files)
        └── config/  (Configuration)
```

### Troubleshooting

**Build fails:**
- Run `make clean` then `make all`
- Check CMake version >= 3.10
- Verify all headers present

**Shell won't run:**
- Verify binary was built
- Check permissions: `chmod +x install/bin/toriginal_shell`
- Run with: `./install/bin/toriginal_shell`

**Compilation warnings:**
- Safe to ignore in production builds
- Check for actual errors
